# Recomp

A gym tracker for body recomposition. Installable on your phone and usable on a laptop, with your data in your own account so both show the same thing.

What it does: an automated training program with warm-up ramps and progression, an exercise library with illustrations and a machine guide with real photos, a check-in every four days with progress photos, a food area built for Indian eating with the full nutrient panel, running and incline walking, and a weekly review of what is working and what needs attention.

Live at https://ri1wik.github.io/gym-tracker/

## Develop

```bash
npm install
npm run dev
```

`npm test` runs the domain tests. `npm run build` type-checks and builds. Every push to `main` deploys through GitHub Actions.
